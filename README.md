# 自动档灵梦 V3.0 支持steam最新版 新典 原典

Windows 本地工具：新典 V3.0 与原典 V2.0 独立运行。作者：B站冬月爱吃沙丁鱼。

## 使用
启动发布版自动档灵梦.exe，选择版本。F8 启停，F9 停止输入。新典提供避弹、射击、安全拾取 P/B、安全追击、自动 Bomb/仅决死、无敌和无限资源，以及普通 1–6 面的暂停后重开/跳关。关卡工具会丢弃当前面的进度，普通流程保留当前资源。

路线学习默认关闭，需要同时开启自动射击并实际发送操作。道中仅比较通过安全检查的常规路线与回中偏好，不改写专用符卡路线，不包含 Extra 学习。有效记录不代表保证无伤。

发布版不含循环。使用辅助后，本次游戏进程禁止保存 Replay；关闭工具不会解除，重启游戏恢复。跳关后的 Replay 一致性不受支持。

新典界面 920×900，原典界面与逻辑保持 V2.0。日志和运行文件在临时目录中，正常关闭后由启动器清理；异常终止可能残留。学习经验单独保存在 `%LOCALAPPDATA%/ReimuDodge/v3-new/`，不会随临时目录清理。删除该目录可重置学习。

## 构建（Windows x64）
推荐 Python 3.12。先执行 `python -m pip install -r requirements.txt`，再执行 `python build.py`，输出 `dist/自动档灵梦.exe`。构建需要 Tkinter（官方 Python 安装通常提供）。

`new/core.dll` 是随源码提供的运行核心。若要自行重建，在 Visual Studio x64 Native Tools Command Prompt（安装 C++ 工具链）运行 `new/build_core.cmd`，然后重新打包。C++ 源码为 `new/core.cpp` 和 `new/shooting.hpp`。

构建脚本默认重新构建两套后端；维护者若放入 `classic-original.exe`，会原样封装该原典文件。官方本次发布使用原始 V2.0 原典文件，其哈希见 RELEASE_SHA256.json。

游戏读取和修改有版本校验，只适用于代码内记录的受支持 Steam 游戏版本。源码不包含游戏或补丁资源。

## 目录
- `new/`：新典界面、策略、训练、经验记录及 C++ 核心。
- `classic/`：V2.0 原典源码。
- `launcher/`：选择窗口、隔离启动及临时文件清理。
